# niko0xdev/skills

A collection of reusable skills and agent workflows for coding and product work.

## Product Deep Research

`product-deep-research/` is a cross-harness Product Intelligence skill for **Claude Code, Codex, Pi, and OpenCode**. It performs evidence-driven competitor research, trend discovery, user-voice analysis, technology scouting, opportunity scoring, and recurring product reviews.

Core decision pipeline:

```text
Signal → Evidence → Insight → Opportunity → Hypothesis → Score → Recommendation → Human decision
```

See [`product-deep-research/README.md`](product-deep-research/README.md) for setup and usage.

The original engineering workflow skills remain under `skills/`, including requirements analysis, brainstorming, implementation planning, worktree management, feature implementation, testing, lint/cleanup, commit authoring, and pipeline orchestration.
